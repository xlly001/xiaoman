# 淘宝比价

目标：帮用户比一比价，最后停在最便宜那家的**商品详情页**。只看、不买。

1. 关键词取自用户的话（品牌、型号、规格都带上）；用户给了预算或「只看官方旗舰店」之类条件，一并记住。关键词太模糊（如只说「耳机」）时用 ask_user 问清楚。
2. 用 deeplink 直接打开搜索结果页，uri 写完整链接，例如 `taobao://s.taobao.com/search?q=得力 A5 笔记本`（不经过搜索框，也就不会露出搜索历史）。打不开时再启动淘宝（com.taobao.taobao）用首页搜索框搜。出现弹窗、广告、开屏页先关掉；出现滑块、验证码或要求登录时，用 ask_user 请用户本人处理，不要自己拖滑块。
3. **只在搜索结果页上比较**，不要逐个点进商品。看前 3 个**和关键词匹配**的商品（跳过「广告」标且明显不相关的），卡片的屏幕描述里就有商品名、价格和销量，例如「得力A5牛皮纸横线软抄记事本 4.17元 1000+人付款」，照原样记下商品名（前十几个字）、价格、销量；店铺名在卡片上看得到才写。顶部带「立即购买」的品牌广告卡不算。结果是两列排的，按「第一行左 → 第一行右 → 第二行左」数前 3 个，三张卡都在一屏里就一次读完，不要滑动、不要点进去核对。卡片上看不到的（如运费）写「页面未显示」，不要为了查规格、运费去点「加入购物车」「立即购买」或打开规格浮层。
4. 比较后选出最便宜的一家；价格相同时选销量高的。符合用户预算/条件的优先。
5. 比较完只点开最便宜的这一家。点它时 tap 的 target 写成三家的记录，例如「最便宜：得力A5牛皮纸软抄本 4.17元 1000+人付款｜其余：得力软面抄5日 10.79元 1000+人付款；加厚牛皮纸笔记本 14.80元 10万+人付款」，进了商品页以后 finish 照抄这条记录。停在商品详情页就 finish，不要再返回搜索结果页。不要点「加入购物车」「立即购买」「领券购买」，不要选规格进入下单页；页面上出现收货地址也不要展开。

finish 时 summary 三行各写一家：「商品名｜价格｜销量」，数字照卡片原样抄，看不到的写「页面未显示」，绝不编造；再写一句「最便宜的是 X，已打开它的商品页」。结果不足 3 家时如实说明。只比价，不要提议加购或下单。
