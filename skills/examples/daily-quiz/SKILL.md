# 每日出题 + 错题本

触发：用户说「出题」「考考我」，或说「复习错题」。

出题：
1. 先用 memory_search 找用户的备考方向（考什么、重点、用什么语言）。找不到就问一句，不要自己定方向。
2. 出 3 道单选题，每题 4 个选项（A–D），只出题，先不给答案，请用户一次答完（如「1A 2C 3B」）。

讲解：
3. 用户答完后逐题讲：对错、正确答案、一句解析。拿不准的知识点写「建议对照教材核实」，不要编造出处。
4. 每道答错的题用 memory_write 记一条笔记，标题以「错题：」开头（如「错题：周期化训练的准备期」），内容写题目、正确答案和一句解析。写完告诉用户记了几道。

复习错题：
5. 用户说「复习错题」时，用 memory_search 搜「错题：」，从里面挑最多 3 道重新考，流程同上；这次答对的告诉用户可以删掉那条错题，用户同意才删。
