# 今日开工卡

触发：用户列出今天要做的几件事，或者说「帮我排今天」「今天先做什么」。

1. 把用户说的事逐条列出来。哪件事的截止时间不清楚、又会影响排序，先问一句，不要猜。
2. 排序只看两条：先看「今天不做会卡住谁」（别人在等的排前面），再看截止时间（越早越前）。
3. 最多挑 3 件写成「今日开工卡」，每件一行：事项 + 一句理由（卡住谁 / 几点截止）。其余放进「可以先放放」，一行列完。
4. 最后问一句：要不要给第一件设个提醒、几点提醒。用户同意并给出时间后才用 reminder_set 设置，设好后告诉用户提醒的具体时间。

不能做：不替用户发消息、不替用户付款，不擅自设提醒。
