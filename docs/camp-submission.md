## 一、Agent介绍

**Agent名称：** 小满（Xiaoman）

**解决的问题：**

手机上的日常小事被拆散在几十个 App 里：查快递要开购物 App，记事情要开备忘录，改设置要翻系统菜单。通用聊天助手只能“告诉你怎么做”，不能“替你做”；把手机整个交给云端 Agent，又不放心。

小满要解决的是三件事：

1. **记得住**：你说过的偏好、地址、常用单号，它写进本地记忆，下次直接使用。
2. **做得到**：通过 Android 无障碍服务读取屏幕、点击、输入，真正替你操作其他 App。
3. **管得住**：付款、发送、删除等高危动作必须经过独立于模型的 Sentinel 审核，模型绕不过去。

**一句话介绍：**

> 小满是一个住在你手机里、会记事、能替你操作 App 的私人 Agent。

**开发方式：这是二次开发项目。**

基础来自 TRAE 训练营课程开源项目 [aduoge/xiaoman](https://github.com/aduoge/xiaoman)（MIT 协议）。原项目已经提供了 Agent 骨架、无障碍操作循环、Sentinel 安全层、记忆与技能的基础能力；我在此基础上做了界面重构、任务系统、流式回复、内置语音/识别和评测等改造。

**哪些是原项目的，哪些是这次二次开发加的：**

| 部分 | 来源 |
|---|---|
| Agent 骨架、无障碍读屏/点击、Sentinel 允许/询问/拒绝、记忆与技能基础、MCP 客户端 | 课程开源项目 `aduoge/xiaoman`（MIT） |
| Open Muse + Today 风格、全局 Dock、能力页、任务页、任务详情、日记、搜索、常用指令 | 本次二次开发 |
| 任务队列、断点恢复、流式回复、TTS/ASR/OCR 接入、评测底座、中英文国际化、Spec 与交接文档 | 本次二次开发 |

> 原项目版权归 aduoge 所有；本仓库的修改与新增部分版权归 xllyxx and contributors，继续沿用 MIT 协议。

**它现在能做什么：**

- **聊天与记忆**：主对话 + 任务子对话；会话、任务、日记、常用指令全部本地持久化。
- **操作手机**：派一个目标（“帮我查最近一票快递”），它自己截屏、看节点树、规划下一步；成功的路径会沉淀成经验。
- **任务队列与断点恢复**：任务可以排队、暂停、继续、取消；每走一步写检查点，杀进程重开后能从第 N 步之后继续，而不是从头重放。
- **技能与 MCP**：新场景用 `SKILL.md` / `flow.yaml` 添加，不用重新打包；高德、滴滴、12306 等服务可在能力页勾选。
- **听、说、看**：语音输入（ASR）、回复朗读（TTS）、图片取字（OCR）。用 DeepSeek 时走官方 `/v1/tools/{asr,tts,ocr}`，与聊天共用同一个 Key；其它服务商自动回退系统能力。朗读支持「自动朗读回复」和每条回复下方的单独「朗读 / 停止朗读」按钮，点哪条读哪条。
- **顺手可用的细节**：消息文本可长按拖选，只复制需要的片段；助手气泡同时保留整条复制按钮。
- **安全边界**：密码框、`FLAG_SECURE` 页面直接拒绝；支付/发送/删除前必须你确认；每次决策写审计记录。

**关于朗读（TTS）在哪里：**

- 自动朗读入口：**设置 → 内置能力 → 自动朗读回复**，音色可选「海星（女声）」或「暗潮（男声）」；打开后助手最终回复到达时整段朗读。
- 逐条朗读入口：每条助手回复下方有一个小喇叭按钮，点一下只读这一条；播放时按钮变成「停止朗读」，再点即停。手动朗读和自动朗读互斥，同一时刻只有一条在播。
- 引擎：DeepSeek 模型默认调用官方 `/v1/tools/tts`；其它服务商使用系统 `TextToSpeech`，没有系统引擎时静默失败并恢复按钮状态。
- 同一块设置里还有 ASR 语音输入和 OCR 识别模式（纯文字 / 版面识别），配图见第 05 张。
- 文本复制：长按任意消息可拖选片段后复制；助手消息下方的小图标可一键复制整条。

**这次具体做了什么（可直接写进帖子正文）：**

1. **逐条朗读**：在 `AppGraph` 里增加统一的朗读状态 `speaking` 与 `speak / stopSpeaking / toggleSpeaking`，助手气泡下方新增「朗读 / 停止朗读」按钮；自动朗读和手动朗读共用同一条播放链路，新播放会先停掉旧的，保证同一时刻只有一条在播。
2. **停止联动**：底部 Dock 的停止按钮从「只停 TTS」改为 `graph.stopSpeaking()`，任务停止时朗读状态一起清空，按钮自动恢复。
3. **局部复制**：消息文本改用 Compose `SelectionContainer`，长按出现选择手柄，可只复制选中的句子；助手气泡保留整条复制按钮。为避免手势冲突，去掉了原先「长按整条复制」。
4. **范围对齐**：主对话和任务子对话（`ChatScreen` / `TaskDetailScreen`）都接入了同一套按钮与状态，不只改主聊天页。
5. **国际化与验证**：新增 `chat_speak` / `chat_stop_speaking` 中英文 key（402/402 对齐）；`:app:testDebugUnitTest`、`:app:assembleDebug`、`:app:lintDebug` 全部通过，并在 API 35 模拟器上实测「朗读 → 停止朗读」与长按选择复制。
